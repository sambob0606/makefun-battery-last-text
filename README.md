One line for make.fun's "The Battery's Last Text to Its Charger" bounty: the phone battery's final message to the charger it waited for all day. The program scores three candidate lines on the judge's own criteria — a real joke with a turn that pays off in the final words first, then a voice a person would actually type, then spending the 200 characters well, then a fresh angle — and writes the winner to `/output/entry.txt`. The winner is:

> hey. 1%. you left me on 4% all afternoon so your earbuds could live. i hope the lamp was worth it. goodbye, i'm taking your alarms with me.

## Run it

```sh
python3 main.py
```

It writes the line (139 characters, one line, no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (1–200 characters, not only whitespace, exactly one line) before exiting.
